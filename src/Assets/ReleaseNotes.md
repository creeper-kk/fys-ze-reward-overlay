## v1.3.0.1 更新内容

- 设置左侧新增「KZ 地图探测」。通过 CS2 GSI 读取当前地图，右侧显示地图名和玩家当前的 CKZ / VNL 模式。
- 通过 CS2KZ 官方 API 查询各路线的 NUB / PRO Tier。默认按当前模式显示难度，也可手动选择要看的模式。
- 官方未收录的 KZ 地图在难度栏显示「非全球图」，右侧仍会持续更新当前模式。
- 「显示信息」新增 KZ 的「地图难度」和「模式」。悬浮窗和 OBS 会随地图在 KZ 信息和 ZE 奖励之间切换。两类地图均可显示英文名和叠层文本中匹配的译名。
- 「外观与字体」新增独立的 KZ 文字颜色，可逐项设置 T0～T10、VNL 和 CKZ，并在右侧即时预览。
